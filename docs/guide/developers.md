# Developer guide

## Prerequisites

**Node ≥ 18** and **pnpm**. The skill and MCP server read **generated** files,
so build once after cloning.

```bash
git clone https://github.com/4aykas/tebin-style.git
cd tebin-style
pnpm install
pnpm build      # generates dist/*, assets/png/*, DESIGN.md, registry/index.json, rules/dist/*
```

## Output formats

Each theme generates four token files in `themes/<id>/dist/`:

| File | Use when target is | How to apply |
|------|--------------------|--------------|
| `tokens.css` | any project that can load CSS | paste the `:root { … }` block into the global stylesheet, or import the file |
| `tailwind.css` | Tailwind v4 | paste the `@theme { … }` block into the file that has `@import "tailwindcss";` |
| `theme.ts` | React / CSS-in-JS / TypeScript | import the exported `as const` object; use the exported type |
| `tokens.dtcg.json` | Figma plugins, Style Dictionary, other tooling | feed into the tool that consumes DTCG |

Prefer the format that matches the target's existing styling approach. Do not
mix formats in one project. `tokens.css` and `tailwind.css` carry transformed
values (hex lowercased, font families joined); `tokens.dtcg.json` and
`theme.ts` keep the canonical source values.

## What is generated, what is hand-edited

Hand-edited, per theme: **`tokens.json`** (the canonical DTCG source),
**`theme.json`** (metadata and the asset list), **`design.intro.md`** (the
prose opening of the generated DESIGN.md). Repository-wide:
**`rules/rules.json`**.

Everything else is generated by `pnpm build` and guarded by `pnpm check`:
`dist/*` (including `colors.csv`), `assets/png/*` with its `manifest.json`,
`preview/palette.svg` + `.png`, `DESIGN.md`, `registry/index.json`,
`rules/dist/rules.md`. Edit the sources, run the build, commit both.

PNG bytes are never byte-compared — staleness is detected through the raster
manifest (source SVG sha256 + the size ladder), so differing resvg builds
cannot fail CI for their own reasons.

## Development scripts

```bash
pnpm validate   # JSON Schema + integrity checks
pnpm build      # generate everything listed above
pnpm check      # fail if generated files drift from source
pnpm test       # run the test suite
```
