# tebin-style

A registry of brand themes for AI agents: DTCG tokens, brand assets, design
rules, an MCP server and a skill. TypeScript ESM, strict, tests in
`test/*.test.ts` (vitest).

## Commands

Node 22 and pnpm 11 (pinned in `packageManager`). Run `pnpm install` first.

- `pnpm verify`: the gate. Typecheck, validate, lint themes, check drift, test.
  CI runs it on Linux and Windows. It must pass before you commit.
- `pnpm build`: regenerate every generated file, including the MCP bundle.
- `pnpm build:mcp`: rebuild only `mcp/dist/server.mjs`.
- `pnpm start:mcp`: run the bundled MCP server over stdio.

Dependency updates are manual: `pnpm update`, then `pnpm build`, then
`pnpm verify`.

## Layout

- `themes/<id>/`: one theme. Sources are `tokens.json`, `theme.json`,
  `design.intro.md` and `assets/` (except `assets/png/`).
- `rules/rules.json`: design rules.
- `src/`: the library. `scripts/`: build, check and release scripts.
- `mcp/`: the MCP server, bundled to `mcp/dist/server.mjs`.
- `skills/tebin-style/`: the agent skill. `.claude-plugin/`: the plugin and
  marketplace manifests.

## Generated files

These are generated by `pnpm build` and committed. Never edit them by hand:

- `themes/*/dist/**`, `themes/*/DESIGN.md`
- `themes/*/assets/png/**`, `themes/*/preview/**`
- `registry/index.json`, `rules/dist/**`
- `mcp/dist/server.mjs` (rebuild after changing `mcp/` or `src/`)

Change the source, run `pnpm build`, commit both. `pnpm check` fails CI when
a generated file is stale.

## Release

- Push a tag `v<version>` from a commit on `main`. The tag must equal the
  `package.json` version, and `CHANGELOG.md` needs a `## <version> — <date>`
  entry (`scripts/check-release.mjs`).
- The package is private. There is no npm publish. The release attaches the
  brand ZIP, the skill ZIP, a SHA-256 file per ZIP and build provenance.

## Boundaries

- `.input/` holds private brand material. It stays untracked.
- Changing a brand value (colour, type, logo) needs the owner's decision.
  See #72, #73, #74.
